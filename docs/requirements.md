# 需求

读取 Razer DeathAdder V3 Pro 无线鼠标电量的 Windows 小工具，只用 Python 标准库（ctypes 调系统 DLL），
不依赖 Razer Synapse，也不和它冲突。

## 设备与协议（已在实机上验证，2026-10-25）

- 2.4G 接收器 `VID 1532 / PID 00B7`；有线模式 `PID 00B6` 同协议，但未实机验证。
- 控制接口是 `MI_00` 鼠标集合，Feature Report 长度 91（报告 ID 0 + 90 字节），只能以 0 访问权限打开。
- 报告格式：状态、事务 ID `0x1F`、剩余包数(2)、协议类型、数据长度、命令类、命令 ID、80 字节参数、
  CRC（第 2–87 字节异或）、保留字节。
- 电量：命令类 `0x07` / ID `0x80`，回复参数第 1 字节 0–255，按 `round(raw*100/255)` 换算百分比。
- 充电状态：命令类 `0x07` / ID `0x84`，回复参数第 1 字节非 0 表示充电中。
- 回复状态 `0x02` 成功、`0x01` 忙（重试）、`0x03` 失败、`0x04` 超时（鼠标休眠或关机）、`0x05` 不支持。

## 验收条件

1. `python app.py` 在鼠标在线时打印型号、电量百分比和是否充电，退出码 0。
2. `python app.py --json` 输出 `{"model", "percent", "charging"}` JSON，便于脚本调用。
3. 找不到设备时提示“未找到”并以退出码 2 结束；鼠标休眠、超时或回复异常时提示原因并以退出码 3 结束，不抛未处理异常。
4. 回复状态为“忙”时继续轮询；回复的事务 ID、命令类、命令 ID 与请求不符（例如 Synapse 的回复）时
   不当作电量，并与失败回复一样重新发送请求，最多 3 轮。实测 Synapse 运行时约 1% 的单次读取会被它打断。
5. `python app.py --tray` 在系统托盘显示电量数字图标，提示文字含百分比和充电状态，
   默认每 60 秒刷新，右键菜单可“立即刷新”和“退出”；电量 ≤ 20% 时图标变红，读取失败显示“?”。
   同一时间只允许一个托盘实例。
6. 协议编码、解析、换算与重试逻辑有不依赖硬件的单元测试，在 Linux CI 上也能运行；
   `app.py --self-test` 不访问硬件。
7. 不联网、不写日志或配置文件，不需要管理员权限。

## 失败场景

- 接收器拔出或鼠标关机：退出码 2/3，托盘显示“?”并继续定时重试。
- Razer Synapse 同时访问设备：回复“忙”时重试，最多 10 次后报告超时。
- 非 Windows 平台：提示仅支持 Windows，退出码 1。
